# Документация СМИБ

Репозиторий содержит документированную информацию СМИБ в соответствии с п. 7.5 ISO/IEC 27001:2022.

## Структура
- 01-politika/ — политика ИБ верхнего уровня
- 02-chastnye-politiki/ — частные политики
- 03-procedury/ — процедуры и регламенты
- 04-instrukcii/ — инструкции, шаблоны, чек-листы
- 05-zapisi/ — шаблоны записей

## Порядок внесения изменений
1. Создать ветку с осмысленным именем от main.
2. Внести изменение, зафиксировать коммитом с указанием причины.
3. Открыть запрос на слияние (pull request), назначить рецензента.
4. Устранить замечания рецензента отдельным коммитом.
5. После одобрения выполнить слияние в main и пометить редакцию тегом.
Прямая запись в main запрещена.
